# deployment/README.md
# Production Deployment Quick Reference

This directory contains all production deployment files and scripts for the KIOSK application.

## 📁 Directory Structure

```
deployment/
├── README.md                    # This file
├── nginx/
│   └── nginx.prod.conf         # Production nginx reverse proxy config
├── ssl/                        # SSL certificates (created during setup)
│   ├── fullchain.pem          # Let's Encrypt certificate
│   └── privkey.pem            # Private key
└── scripts/
    ├── setup-secrets.sh       # Initialize production secrets (run once)
    ├── deploy-prod.sh         # Deploy/update application
    ├── backup-db.sh           # Create database backup
    └── rollback.sh            # Emergency rollback to previous version
```

## 🚀 Quick Start - First Time Production Setup

### 1. Initial Server Setup (One Time)
```bash
# On production server
cd /opt/kiosk

# Generate production secrets
./deployment/scripts/setup-secrets.sh

# This creates: /opt/kiosk/secrets/.env.prod
# IMPORTANT: Save the displayed secrets in your password manager!
```

### 2. Deploy Application
```bash
# On production server
cd /opt/kiosk

# First deployment
./deployment/scripts/deploy-prod.sh

# This will:
# - Pull latest code from git
# - Build Docker images
# - Start all services (postgres, backend, frontend, nginx)
# - Run database migrations
# - Verify deployment
```

### 3. Set Up SSL Certificate (One Time)
```bash
# Install certbot
sudo apt install -y certbot python3-certbot-nginx

# Stop nginx temporarily
docker compose -f docker-compose.prod.yml stop nginx

# Obtain certificate (replace with your domain)
sudo certbot certonly --standalone \
  -d kiosk.yourdomain.com \
  --email your-email@example.com \
  --agree-tos

# Copy certificates
mkdir -p /opt/kiosk/deployment/ssl
sudo cp /etc/letsencrypt/live/kiosk.yourdomain.com/fullchain.pem \
        /opt/kiosk/deployment/ssl/
sudo cp /etc/letsencrypt/live/kiosk.yourdomain.com/privkey.pem \
        /opt/kiosk/deployment/ssl/
sudo chown -R $USER:$USER /opt/kiosk/deployment/ssl
chmod 644 /opt/kiosk/deployment/ssl/fullchain.pem
chmod 600 /opt/kiosk/deployment/ssl/privkey.pem

# Update nginx config with your domain
nano /opt/kiosk/deployment/nginx/nginx.prod.conf
# Replace 'server_name _;' with 'server_name kiosk.yourdomain.com;'

# Restart services
./deployment/scripts/deploy-prod.sh
```

## 🔄 Regular Operations

### Deploy Updates
```bash
# When you have code changes to deploy
cd /opt/kiosk
./deployment/scripts/deploy-prod.sh
```

### Create Database Backup
```bash
# Manual backup
cd /opt/kiosk
./deployment/scripts/backup-db.sh

# Backups saved to: /opt/kiosk/backups/
# Retention: 7 days (configurable in script)
```

### Emergency Rollback
```bash
# If deployment breaks production
cd /opt/kiosk
./deployment/scripts/rollback.sh

# Follow prompts to select commit to rollback to
```

## 🔧 Configuration Files

### docker-compose.prod.yml
Production overrides for base docker-compose.yml:
- Removes port exposure for PostgreSQL (security)
- Adds nginx reverse proxy
- Configures resource limits (1-CPU VPS optimized)
- Enables health checks
- Sets restart policies

### nginx.prod.conf
Nginx configuration:
- HTTP to HTTPS redirect
- SSL/TLS termination
- Reverse proxy to backend API
- Static file serving for frontend
- Media file serving (local or S3)
- Security headers

### Secrets (.env.prod)
Location: `/opt/kiosk/secrets/.env.prod`
- Never committed to git
- Generated by setup-secrets.sh
- Contains all production secrets
- Permissions: 600 (read/write owner only)

## 🔐 Security Checklist

After deployment, verify:
- ✅ Firewall enabled (ports 22, 80, 443 only)
- ✅ SSH key authentication (no password login)
- ✅ Non-root user running application
- ✅ .env.prod permissions: 600
- ✅ HTTPS with valid SSL certificate
- ✅ Strong database password (25+ chars)
- ✅ Unique secrets (different from development)
- ✅ Regular backups configured

## 🆘 Troubleshooting

### Container Won't Start
```bash
docker compose logs backend
docker compose logs postgres
```

### SSL Certificate Issues
```bash
# Test renewal
sudo certbot renew --dry-run

# Manual renewal
sudo certbot renew --force-renewal
```

### Database Connection Issues
```bash
# Check PostgreSQL
docker compose ps postgres

# Test connection
docker compose exec backend python -c "from app.database import engine; engine.connect(); print('✅ Connected')"
```
